### What you will find here
- `requirements/`: System Requirements Documents (SRD) and Link Budgets.
- `architecture/`: High-level block diagrams and Interface Control Documents (ICD).

### Guidelines
> The documentation here dictates the course of development. No drastic hardware or software changes should occur without updating the SRD and Architecture first.
