### What you will find here
- `PCB/`: Native KiCad schematic and layout files.
- `manufacturing/`: Generated outputs for manufacturing and assembly (Gerbers, BOM, Pick and Place).

### Guidelines
> Keep symbol and footprint libraries standardized. The `.gitignore` file is already configured to hide local KiCad backups.
